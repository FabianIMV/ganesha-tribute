# 🐘 Tributo a Sri Ganesha

> ॐ गं गणपतये नमः — *Om Gam Ganapataye Namah*

Un sitio de una sola página en honor a **Ganesha**: el removedor de obstáculos,
señor de los comienzos y patrono de la sabiduría y las artes.

## ✨ Qué contiene

- 🎨 **Ganesha en arte lineal SVG**, dibujado con animación de trazo
- 🌌 Cielo estrellado en canvas y lluvia de pétalos de caléndula
- 🧘 **El cuerpo como enseñanza** — el simbolismo de cada rasgo
- 📿 **Mantras** en devanagari, transliteración y significado
- 🕉️ Los ocho nombres del *Ashtavinayaka*
- 🪔 **Enciende una diya** — deja tu propia lámpara como ofrenda (se recuerda entre visitas)

Todo es un único `index.html` autocontenido: sin dependencias, sin frameworks,
sin build. Respeta `prefers-reduced-motion`.

## 🚀 GitHub Pages

Activa Pages en **Settings → Pages → Deploy from a branch → `main` / root**
y el sitio quedará publicado.
